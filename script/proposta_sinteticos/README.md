# Proposta de dados sintéticos para revisão

**Os registros de `registros-sinteticos.json` foram inventados para testes. Não são observações, resultados de laboratório, nem dados de validação científica.** As duas linhas reais incluídas no arquivo aparecem sob `observacoes_reais_de_referencia_nao_incluidas_como_sinteticas` apenas para transparência e calibração grosseira; não devem ser copiadas para o conjunto sintético.

## Esquema confirmado

- `CorposHidricos` (`waterPath`): `Nome`, `Localizacao`, `Tamanho`, `EhPrivado`. Nome proposto: `SINTETICO-Rio Doce`; `Rio Doce` é o nome oficial do corpo hídrico. A extensão de 850 km é aproximada para o rio inteiro, segundo a [ANA](https://www.gov.br/ana/pt-br/assuntos/gestao-das-aguas/planos-de-recursos-hidricos/planos-de-recursos-hidricos-de-bacias-hidrograficas/planos-de-bacias-hidrograficas-interfederativas/doce), não para o ponto; não é apropriada como medida de trecho. Não inserir esse tamanho sem decidir um valor de extensão que corresponda ao requisito atual da aplicação.
- `Coletas`: `CorpoHidricoId`, `DataHora`, `Latitude`, `Longitude`, `ProfundidadeMetros`. A API exige data com fuso e rejeita data futura.
- `Medicoes`: `ColetaId`, `codigoMedicao`, `valor`, `unidade`, `censurado`, `limite`. A API aceita códigos enum como string (`Ph`, `OxigenioDissolvido`, `Turbidez`, `Iqa`) e exige unidades textuais; `Iqa` usa pontos e escala de 0 a 100.
- `MetaisPesados`: `ColetaId`, `Nome`, `Concentracao`, `Unidade`. No contrato: Fe/Mn em mg/L; Cr/Ni/Cu/Zn/Cd/Pb em µg/L.
- `Imagens`: URL local obrigatória (`src/resources/imagens/` pelo construtor), data de upload e relações com corpo/coleta. O modelo não persiste data de captura, URL de origem ou licença. A referência Sentinel no JSON é só metadado externo: não representa um arquivo pronto para carga, nem um registro na tabela `Imagens`.
- O arquivo JSON é uma proposta de dados, não um payload pronto: `corpoHidricoId` está nulo para não inventar ID e precisa ser resolvido somente após cadastro/reuso aprovado do corpo hídrico. A referência de imagem não contém arquivo local e não pode ser carregada na API atual.
- Nenhuma entidade, configuração EF ou migration chamada validação foi localizada. A DDL proposta é nova e independente; não é uma tabela já existente. Ela só é necessária se o projeto quiser persistir a trilha dos critérios/resultados de validação. Para teste efêmero, o JSON pode ser suficiente.

## Regra de geração e critérios de plausibilidade

1. Um corpo hídrico sintético e duas coletas sintéticas no ponto AGERH/PMQQS RDO-15, Linhares/ES, coordenadas -19.41011, -40.05896. O identificador/código do ponto e coordenadas vieram do serviço público PMQQS; os valores das coletas não.
2. Datas locais 24 e 26 de junho de 2025 às 12:00 (-03:00), em torno de uma cena Sentinel-2 adquirida em 25 de junho de 2025 às 15:07:41 UTC. A diferença é 1 dia para cada coleta. O horário exato e a associação a essa estação são escolhas de teste.
3. Faixas exemplificativas não foram geradas como amostras estatísticas nem pretendem reproduzir o Rio Doce: pH 7,2–7,5, OD 5,8–6,1 mg/L, turbidez 12–18 NTU e IQA 68–72 pontos. Os números estão dentro de faixas compatíveis com códigos/unidades do app; pH 6–9, OD mínimo 5 mg/L (classe 2, se aplicável) e turbidez abaixo de 40 UNT são referências regulatórias/de enquadramento, não afirmação sobre o enquadramento do ponto. IQA varia de 0 a 100 e as faixas capixabas são distintas das de outros estados.
4. Fe sintético 0,12–0,16 mg/L e Pb 3–4 µg/L servem para testar representação e unidade. Para orientar ordem de grandeza de Fe, o conjunto local contém dados PMQQS reais no próprio ponto: 0,0791 mg/L em 21/07/2026 e 0,1869 mg/L em 16/06/2026. Esses valores reais estão separados no JSON e não foram reutilizados. Pb é apenas um valor demonstrativo abaixo do limite de 10 µg/L (0,01 mg/L) citado para classe 2 na CONAMA 357; o ponto não foi confirmado como classe 2. Não há alegação de distribuição local de metais nem suporte científico para inferir uma série temporal a partir de duas observações.
5. Os valores sintéticos são determinísticos e pequenos, para exercitar contrato, relacionamento, unidades, repetição/identidade e metadados de imagem; não servem para treinar/avaliar IA, calcular desempenho científico, nem inferir estado real do rio. Não há coliformes, DBO, fósforo/nitrogênio total e resíduo total; logo, o IQA proposto não foi recalculado, e os campos presentes não compõem o cálculo completo NSF/ANA.
6. A imagem é evidência de disponibilidade de um produto de catálogo, não imagem comprovadamente sem nuvens no ponto. A cena não foi baixada nem inspecionada visualmente. A API atual não tem campos para aquisição, origem, licença ou condição de nuvem; se uma imagem for futuramente carregada, preservem-se esses dados em manifesto de proveniência e não se informe `DataUpload` como data de captura.

## Fontes consultadas (acesso em 25/10/2026)

- AGERH, [IQA-ES / Programa QualiRios](https://servicos.agerh.es.gov.br/iqa/home.php): descreve pontos e série pública; catálogo da bacia do Jucu também exemplifica campos de código/nome/localização/coordenadas: https://servicos.agerh.es.gov.br/iqa/action_pesquisa_bacia.php?Bacia=Jucu. Escopo de localidade do conjunto proposto foi confirmado no metadado PMQQS arquivado no repositório, não atribuído à estação AGERH.
- Samarco/PMQQS, [camada pública FeatureServer](https://gis.samarco.com/arcgis/rest/services/R01_Camadas/REP_PMQQS_Matriz_Invertida_Manual/FeatureServer/0): localização e observações reais de referência estão registradas em `script/data/PMQQS-RDO15-LEIA-ME.json` e `script/data/pmqqs_rdo15.csv` (fonte original preservada em `pmqqs_rdo15_raw.json`).
- INPE, [item Sentinel-2 L2A no STAC Browser](https://data.inpe.br/stac/browser/collections/S2_L2A-1/items/S2C_MSIL2A_20250625T150741_N0511_R082_T19LBJ_20250625T194417): item publicado com aquisição inferida diretamente do identificador do produto (2025-06-25 15:07:41Z), tile T19LBJ. A cobertura pontual e nuvens precisam de inspeção/download antes de anexar ao registro.
- ANA, [IQA: composição, pesos e faixas estaduais](https://www.ana.gov.br/portalpnqa/indicadores-indice-aguas.aspx): nove parâmetros, intervalo 0–100 e diferenças entre faixas estaduais.
- ANA, [Oxigênio Dissolvido](https://qualidadedaagua.ana.gov.br/od.html): valores mínimos por classe conforme Resolução CONAMA 357/2005.
- CONAMA, [Resolução 357/2005 (PDF oficial republicado pela ANA)](https://www.ana.gov.br/portalpnqa/Publicacao/RESOLUCAO_CONAMA_n_357.pdf): referências regulatórias de águas doces. Não substitui confirmação do enquadramento local.
- INPE, [distribuição de imagens CBERS](https://www.gov.br/pt-br/servicos/obter-imagens-de-sensoriamento-remoto-da-terra-geradas-pelo-satelite-cbers-4?id=12267&origem=servico): fonte institucional consultada sobre acesso a imagens; não foi usada para afirmar uma cena CBERS específica.
- UFES, [tese sobre elementos-traço na bacia do Rio Santa Maria da Vitória](https://repositorio.ufes.br/server/api/core/bitstreams/56e40747-d4f1-4333-a5df-acb03e1b0a95/content): valores em outro rio e outras campanhas; não extrapolados para o Rio Doce. Já catalogada em `script/research_metal_measurements.csv`.

## SQL e execução

- `validacoes-ddl.sql` propõe a tabela nova `waterPath.ValidacoesSinteticas`; a aplicação atual não possui tabela de validação. DDL não foi executada.
- `validacoes-insert.sql` propõe linhas de auditoria ainda `PENDENTE` e usa `ON CONFLICT ("Chave") DO UPDATE` para repetição idempotente. Não foi executado.
- Não existe `script.py`. O arquivo existente é `script/import_agerh_iqa.py`, cujo `--apply` importa CSV oficial AGERH após configuração explícita de mapeamento e aponta para rotas da API. Não aceita estes registros JSON e não deve ser usado para inseri-los. Logo, não há comando de população sintética confirmado no repositório. Somente inspeção de opções: `python script/import_agerh_iqa.py --help`.
- A importação real futura exigiria preparação de corpo/ponto e uma ferramenta/fluxo novo que aceite o formato confirmado, além de usuário autenticado. Nenhuma credencial foi incluída nesta proposta. Nada aqui foi gravado no banco.
